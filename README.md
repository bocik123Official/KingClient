# King Client 👑

Premium Minecraft Java Edition client for KingMC and more!

## Build from source

```bash
./gradlew build
```

The compiled jar will be in `build/libs/KingClient-1.0.0.jar`

## Controls

- **Right Shift** - Open King Client Menu
  - Toggle modules on/off
  - Click "Cosmetics" button to open cosmetics shop

## Modules

| Module | Description | Status |
|--------|-------------|--------|
| HUD | FPS, Server IP, Coordinates | ✅ |
| Keystrokes | Shows W/A/S/D and other keys | ✅ |
| CPS Monitor | Clicks per second (LMB + RMB) | ✅ |
| Ping Display | Server ping with color coding | ✅ |
